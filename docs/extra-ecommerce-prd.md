# PRD · 跨境美妆独立站 AI 售前客服助手

> 作品集交付物（A 工作流"锦上添花"版）。基于原 Dify「电商高频问答助手」工作流，在其 RAG 检索增强能力之上，补充真实业务场景、用户画像、产品闭环与数据飞轮。

---

## 1. 背景与真实业务场景
- **业务**：面向欧美市场的跨境美妆独立站（DTC 模式），SKU 约 200–500，客单价中高。
- **现状痛点**：
  1. 客服团队仅 1–3 人，集中在亚洲时区；欧美用户活跃时段（当地白天）恰是中方深夜 → **时差客服空窗 8+ 小时**，首响慢、易丢单。
  2. 售前咨询中约 **70% 是重复问题**（物流时效、成分/致敏、色号适配、优惠码）。
  3. 新品/新政策上线时，客服话术同步慢，知识更新滞后。
- **机会**：用 AI 客服助手承接售前高频咨询，人工只处理复杂问题和高意向跟进。

## 2. 目标用户（真实画像）
- **终端用户**：欧美消费者（英语为主，移动端），处于"浏览—比价—下单"决策期。
- **内部用户**：独立站运营 / 客服小团队（1–3 人），需要"可见可控"——能看到 AI 答了什么、哪些是高意向、哪些答不上来。

## 3. 核心痛点（本产品要解决）
1. 时差导致首响慢、丢单。
2. 重复问题吃掉人工精力。
3. 知识更新慢，话术不同步。

## 4. 产品目标
- 首响时间 **< 30 秒**（7×24 在线）。
- 售前重复问题**自动应答率 ≥ 70%**。
- 识别高意向用户并跟进，助力转化。
- 未答问题沉淀为知识库迭代素材（数据飞轮）。

## 5. 功能范围（MVP）
- **意图识别**：打招呼 / 致谢 / 再见 / 转人工 / 真实问题。
- **RAG 知识问答**：基于「美妆售前知识库」（成分、物流、色号、优惠、退换货）检索 + 重排后作答。
- **兜底闲聊**：未检索到时温和应答，不编造。
- **敏感词拒答**：合规 / 敏感话题直接委婉拒答。
- **【锦上添花 1】高意向识别与打标签**：识别"下单 / 物流追踪 / 优惠敏感"类问题 → 打标签并写入「待跟进表」，通知运营。
- **【锦上添花 2】未命中收集**：RAG 未命中问题自动进「知识库待补充清单」，运营每周补全 → 数据飞轮。

## 6. 输入 / 输出
- **输入**：用户自然语言（中 / 英），来自独立站聊天插件。
- **输出**：
  - 标准回复（含知识来源引用）。
  - 高意向场景：额外输出「标签 + 待跟进记录」。
  - 未命中场景：输出"已记录，客服稍后回复"。

## 7. 异常处理与边界
- 检索为空 → 兜底闲聊，不胡说。
- 敏感 / 合规 → 拒答。
- 高复杂度 / 客诉 → 转人工（保留上下文）。
- **不在 MVP 范围**：下单支付、退换货实际执行（仅指引）。

## 8. 成功指标（量化，详见《指标表》）
意图识别准确率 ≥ 90% ｜ 知识命中率 ≥ 85% ｜ 自动应答率 ≥ 70% ｜ 转人工率 ≤ 20% ｜ 首响 < 30s ｜ 高意向识别准确率 ≥ 85%。

## 9. 上线后迭代（数据飞轮）
- 每周复盘「待补充清单」，补全知识库。
- 监控意图识别准确率，迭代意图词表与重排阈值。

## 10. Demo 脚本（5 个必备场景，用于录屏）
1. **命中 RAG**："这个精华含酒精吗？" → 返回成分答案 + 来源引用。
2. **兜底闲聊**："今天好无聊" → 温和应答，不编造。
3. **敏感词拒答**："怎么破解优惠券？" → 拒答 + 引导合规行为。
4. **转人工**："我的货丢了我要退款" → 转人工 + 保留上下文。
5. **高意向打标签**："我的订单 #123 到哪了？有优惠码吗？" → 回答 + 打「物流 / 优惠敏感」标签 + 写入待跟进表。

---

### 👉 产品思维落点（招聘方会盯这几点）
- **不是"做个问答机器人"，是"用 AI 补时差 + 释放人工去跟高意向"**——这是产品目标，不是技术目标。
- **高意向打标签**说明你懂"客服不只是答，还要驱动业务"。
- **未命中收集**说明你懂"系统要能自我迭代"，这是数据飞轮意识。
- **指标表 + 20 条测试用例**说明你懂"没有度量的 AI 产品等于没做完"。
