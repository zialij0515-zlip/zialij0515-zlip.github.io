## AI 作品集（个人项目）

### ① TikTok 跨境运营课程答疑助手 ｜ C 端 RAG 应用 ｜ Dify + RAG ｜ 2026

**做法**：针对跨境课程学员答疑量大且高度重复的痛点，用 Dify 工作流 + RAG 将 567 条真实学员问答沉淀为 24h 自动答疑；设计意图分流（课程咨询 / 知识问答 / 闲聊 / 敏感词），回答附带来源片段增强可信度，未命中自动进入「待补充清单」形成数据飞轮，敏感词合规拒答。

**结果**：20 条样本实测——意图识别准确率 100% / 知识命中率 85% / 自动应答率 100% / 转人工率 0%；产出 PRD + 指标表 + 录屏 Demo。

### ② AI 智能测试平台 ｜ AI + 测试 RAG 工作流 ｜ FastAPI + LangGraph + ChromaDB + RAG + DeepSeek / 百炼 ｜ 2025 – 2026

**做法**：针对通用 AI 生成用例不可控、不敢进测试流程的痛点，采用需求文档 RAG 检索 + LangGraph 编排生成流程，设人工确认节点 + 确定性覆盖检查（集合运算，不依赖 LLM），把生成结果拉回工程可控范围；支持用例集版本管理 / 回滚 / AI 修改。

**结果**：内置 312 个 pytest 自动化用例全部通过；开源仓库（160 commits）作源码佐证，录屏 Demo 齐备。

### ③轻减日记小程序 ｜ Vibe Coding 独立开发 ｜ 微信小程序 + 云开发 ｜ 2026

**做法**：用 AI 编程工具（Vibe Coding）从零独立开发微信小程序，含首页 / 记录 / 数据 / 个人 4 个模块；按打卡类型隔离数据（早餐 / 午餐 / 晚餐 / 运动 / 放纵餐 5 个集合互不串扰）；97 项食物库长词优先匹配解析热量，基于 Mifflin-St Jeor 公式计算 BMI / 体脂率；莫兰迪低饱和配色，极简 UI。

**结果**：已上线微信小程序，积累真实用户与打卡数据；录屏 Demo 齐备。

###  ④WrenAI × 基金养老数据治理 ｜ B 端 GenBI / 语义层治理 ｜ WrenAI + PostgreSQL + 百炼 Qwen ｜ 2026

**做法**：面向业务 / 投研人员不懂 SQL、「同一指标不同人数」的治理痛点，搭建 PostgreSQL 合成数据底座（5 表约 12 万行）；用 WrenAI 语义层 + SQL pairs 锁定 6 大核心指标口径（养老 AUM / 渗透率 / 定投留存 / 收益率 / 月度申赎 / 用户画像）；定位并解决 WrenAI 0.29 强制 json_schema 导致 DeepSeek 调用失败的问题，切换至百炼 Qwen 以零成本跑通。

**结果**：治理前 SQL 正确率 20% → 治理后 90%（20 题 3 轮实测 18/20 正确）；产出 PRD / 语义层 MDL / 指标测试清单并回填实测数据。
