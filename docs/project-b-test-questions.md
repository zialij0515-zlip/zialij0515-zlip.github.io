## 验收口径（PRD 用）
- **视图命中率** = 命中治理视图的问题数 / 20
- **SQL 正确率** = 生成 SQL 与锁定口径一致的问题数 / 20
- **答案合理率** = 答案数值在合理区间的问题数 / 20
- **目标**：视图命中率 ≥ 90%，SQL 正确率 ≥ 85%（治理后；治理前基线见语义层文档第 0 节，仅 3/6 能稳定答对）。
