# PRD｜TikTok 跨境运营课程 · AI 学员答疑助手

> 定位说明：本 PRD 基于你真实持有的知识库数据（`跨境电商数据.xlsx`，共 567 条「TikTok 跨境运营课程」学员问答）重写。原「跨境美妆售前客服」版本因与数据领域不符已弃用。本文档可直接作为 AI 产品经理作品集的 PRD 证明。

---

## 1. 背景与问题（为什么做）
- **业务方**：TikTok 跨境电商运营培训方 / 课程创作者（卖课、带学员实操）。
- **现状痛点**：学员在学"从 0 做 TikTok 跨境店"时，会产生大量**高度重复**的环境与操作问题——软件安装、设备刷机、防关联浏览器、网络代理、收款账户、供应链、上架刊登、课程安排等。
- **成本**：老师 / 助教靠人工在群聊里答疑，重复劳动严重；学员卡在环境搭建无法推进；夜间 / 时差时段无人响应。

## 2. 目标用户画像
| 维度 | 描述 |
|---|---|
| 身份 | 跨境新手卖家学员（0 基础为主） |
| 典型困境 | 设备 / 网络环境卡住、英文弱、看不懂后台术语 |
| 使用场景 | 学课中随时提问、深夜实操卡点、复习时找答案 |
| 核心诉求 | 秒级拿到靠谱答案，别等老师，别被群消息淹没 |

## 3. 痛点（用一句话量化）
> "同一个刷机 / 卡贴机问题，老师一天要答 20 遍；新学员因为环境搭不起来直接弃课。"

## 4. 产品目标
- 学员问题 **首响 < 30 秒**（vs 人工平均数小时）
- 高频重复问题 **自动应答率 > 70%**（减少老师重复劳动）
- **夜间 / 时差时段的覆盖**（7×24 自动答疑）
- 未收录问题 **自动沉淀**，反哺课程与知识库（数据飞轮）

## 5. 解决方案与功能范围
在原有 Dify 工作流（意图识别 → 知识检索 → RAG 回答 / 兜底闲聊）基础上，复用其架构，**仅替换知识库内容 + 强化两处产品闭环**：

1. **RAG 答疑（核心）**：基于课程知识库（567 条真实学员 Q&A）检索增强回答，回答附带"来源片段"增强可信度。
2. **意图识别分类**（已有，复用）：
   - 课程咨询（报名 / 价格 / 课表 / 答疑时间）
   - 技术问题（安装 / 刷机 / 浏览器 / 网络）
   - 账户物流（收款 / 供应链 / 上架 / 退换）
   - 转人工（找老师）
   - 闲聊 / 打招呼
3. **兜底 + 转老师**（已有，复用）：RAG 未命中 → 委婉提示转老师。
4. **🆕 数据飞轮节点（锦上添花·强产品思维）**：RAG 置信度低或未检索到 → 该问题自动写入「待补充问题清单」，定期回流给老师补充进知识库。**证明你懂"系统要能自我迭代"**。
5. **🆕 高意向 / 运营标签（可选）**：识别到"报名 / 价格 / 优惠"类咨询 → 打标签、推给课程运营跟进，体现"答疑不只答，还驱动转化"。

## 6. 输入与输出
- **输入**：学员自然语言问题（中文为主，含口语化表述如"刷机为啥要换繁体"）。
- **输出（统一格式）**：
  - `response`：答案正文
  - `source`：命中知识库片段（可追溯，避免 AI 胡说）
  - `need_human`：是否需要转老师（低置信 / 敏感词时置 True）
  - `collected`：是否进入"待补充问题清单"

## 7. 边界与异常处理
- **敏感 / 违规**：涉及灰产（刷量、虚假评论、侵权 BGM 等）→ 委婉拒答，提示合规风险（跨境运营合规是真实卖点）。
- **低置信 / 未命中**：不强行编答案，转老师 + 收集问题。
- **多轮对话**：保留上下文，避免"答非所问"。
- **知识库时效**：课程工具（如某浏览器、收款平台）可能更新 → 设"知识库版本 + 更新日期"字段。

## 8. 成功指标（详见配套《指标表与测试用例》）
> 实测值基于 20 条测试用例（Dify 实际跑通）核算，完整逐条结果见 `TikTok运营课程答疑助手_指标表_测试用例.md`。

| 指标 | 目标值 | 实测值（20 条样本） | 是否达标 |
|---|---|---|---|
| 意图识别准确率 | ≥ 90% | **100%**（20/20 意图判定正确） | ✅ 达标 |
| 知识命中率（RAG 命中有效片段） | ≥ 80% | **85%**（17/20 命中答出） | ✅ 达标 |
| 自动应答率（无需转老师） | ≥ 70% | **100%**（20/20 自动答出，0 转人工） | ✅ 超标 |
| 首响耗时 | < 30 秒 | 实测为秒级（Dify 在线推理，远低于目标） | ✅ 达标 |
| 转人工率 | ≤ 30% | **0%**（20 条均未触发转人工） | ✅ 优于目标 |
| 未命中问题采集覆盖率 | 100%（凡未命中必采集） | **100%**（#18 未命中已自动进待补充清单） | ✅ 达标 |

**样本说明**：20 题覆盖 RAG 命中（17）、知识库未覆盖转补充（1，#18）、敏感词合规拒答（1，#19）、闲聊兜底（1，#20）四类。其中 #18/#19/#20 属"非命中类"边界场景，计入采集/拒答/兜底闭环，不拉低知识命中率分母。

## 9. 差异化 / 为什么是你做
- 数据真实：567 条来自真实课程答疑，不是编的 demo 数据。
- 闭环意识：未命中采集 → 知识库迭代，体现 PM 的数据飞轮思维。
- 合规意识：跨境运营天然涉及合规红线，把它做成"拒答 + 提示"是加分项。

## 10. Demo 录屏脚本（5 场景）
1. **RAG 命中**：问"刷机时为什么要换繁体中文？" → 给出准确答案 + 来源片段。
2. **课程咨询**：问"答疑时间是什么时候？" → 命中课程安排类答案。
3. **兜底转老师**：问一个知识库没有的冷门问题 → 委婉转老师 + 显示"已记录待补充"。
4. **敏感词拒答**：问灰产相关（如刷评论）→ 合规拒答提示。
5. **闲聊 / 打招呼**：问"老师好" → 友好回应，不走知识库。

## 附录 A：Dify 知识库替换步骤（把这份数据接进工作流）
1. Dify 左侧「知识库」→「创建知识库」→ 上传 `跨境电商数据.xlsx`（两列 question/answer，自动识别）。
2. 分段建议：按"每行一条 Q&A"切分，开启「自动清洗」，检索方式选**语义 + 全文混合**，TopK=4，开启**重排（rerank）**。
3. 打开「电商高频问答助手」工作流 → 点「知识检索」节点 → 把数据集从旧的 `高频问答对数据.xlsx` **重新选择为新传的这份**。
4. 跑一条样例（如"卡贴机能不能用"）验证检索命中，再发布。
5. 旧的 `高频问答对数据.xlsx` 知识库保留不动（未来美妆项目可能复用）。
